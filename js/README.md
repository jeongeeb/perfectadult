# JavaScript 수정 위치

- `shared/data.js`: 제품명, 가격, 설명, 이미지 경로, 컬렉션 데이터
- `shared/common.js`: 공통 헤더, 메뉴, 화면 크기와 이미지 로딩 기능
- `pages/home.js`: 메인페이지 출력과 상품 마우스 오버
- `pages/product.js`: 상세페이지 출력, 도장 설명, 구매 팝업
- `pages/archive.js`: 아카이브 스크롤 갤러리와 이전·다음 이미지 전환
- `pages/about.js`: 비교용 룩북 선택·이전/다음·스와이프 및 제품 컷 연결
- `pages/manual.js`: 메뉴얼 페이지 출력

`products.js`는 이전 통합 파일이며 새 HTML에서는 사용하지 않습니다.
